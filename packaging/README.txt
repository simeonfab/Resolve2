RESOLVE — ALPHA 0.1 (6 Nov 2026)
================================

Thank you for testing Resolve. Three steps to start:

1. Unzip this folder anywhere (for example your Desktop or Documents).
   Keep resolve2.exe and this README together. Nothing else is needed.

2. Double-click resolve2.exe.
   Windows SmartScreen will warn you, because this alpha isn't signed yet.
   Click "More info", then "Run anyway". You only need to do this once.

3. Connect your AI, then start something new.
   The first screen asks which AI to use. Pick one and press Test:
     - Claude Code (recommended, free if you pay for Claude Pro or Max)
     - Ollama (free and private, runs on your PC, slower)
     - A Claude API key (fastest, you pay per use — set a monthly
       spending limit in your Anthropic console first)
   Or press "Skip for now" to try it with the fixed question set.
   Then Resolve asks about your project and builds a plan with you.

Needs: Windows 10 or 11. Your work is saved on this PC only, in
%APPDATA%\Resolve2 (paste that into File Explorer's address bar).

Stuck or something broke? Open Help → Welcome → "Copy problem report"
and paste it to Simeon, with what you were doing.

If the window doesn't open at all, update your graphics driver (Resolve
draws with OpenGL) and try again, then tell Simeon.
