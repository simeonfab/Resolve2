# Careers Step 3: shell and daily screens (0.9.0)

11 November 2026. Branch `careers/s3-daily`. Not merged: waiting for your review in the preview.

## 1. Check and report first

- **Starter calendars.** Calendars are plain workspace data (name, colour, shown), so a new workspace can start with any set. A new Careers workspace now starts with exactly four: Interviews (terracotta), Closing dates (amber), Follow-ups (green), Offer deadlines (ink soft). The colours come from the existing tokens. No new UI was needed: the built Calendar list shows them with their toggles.
- **Task to record links.** Neither tasks nor events linked to a record before. Both now carry an empty `record_id` (additive, never written while empty), ready for Pipeline records in Step 4. Events also carry `source`, so a tracker-added one can say "Added from Gmail".

## 2. What I built

1. **Switcher.** Each workspace row shows its mode, PM or Careers, from a `mode` kept in the workspace list (PM never written). In a Careers workspace the top row shows "Careers" beside the name.
2. **Sidebar.** YOUR SEARCH with the picker ("All searches", "+ New search (opens the intake)"). Pipeline, My CV, Stats, Interview recorder, Frameworks and Knowledge base open "<Screen>: coming in Step N" with "Unverified: this screen isn't built yet".
3. **Ask Resolve wording** per screen, from the brief's table (set up in Step 1, now visible on these screens).
4. **Home**: the counts line ("0 of 10 applied this week · 1 interview · 1 closing soon"); ADD A JOB above the hero; the hero showing the search's first move with its own reason; Today with each event in its calendar's colour; THIS WEEK (applied against target, today's hunt, Start my daily hunt), WAITING TO HEAR BACK, PIPELINE (All → opens Pipeline), NEW FROM SCOUT, NEEDS A CHECK. Applied, waiting, the stage counts, Scout's finds and the tracker's checks all come from Pipeline (Step 4), so those cards show their empty state, and ADD A JOB says its verdict is unverified until Step 4.
5. **Projects**: each search as a card: name, target, "Next move · …", applied this week against the target, the stage strip (Sourced, Applied, Screen, Interview, Offer), Updated. "+ New search" (and the dashed card) opens the intake. A card opens that search's Pipeline.
6. **Tasks**: Now, Waiting to hear back, Upcoming. "+ Add task" opens a menu: Blank task, then "From a template" (tinted) with the seven templates. Follow up on an application is due in 7 days. A footnote says each links to its Pipeline record; the link is filled once Pipeline exists.
7. **Calendar**: the four starter calendars. The event editor shows "Added from Gmail" for tracker events, with Prep me (Coach, in AI Team) and Open in recorder (Step 8) for interviews.
8. **Fixed**: the first week's tasks are dated in order. Before, "Apply to your first three roles" (Thu) could land before "Fix your LinkedIn headline" (Mon).
