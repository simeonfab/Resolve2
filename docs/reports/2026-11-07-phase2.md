### Bugs found and fixed on the way

- **Plan my day always used the local model**, whatever AI was chosen in Settings: its call could only reach a local server. It now goes to Claude Code, Codex, the Claude or OpenAI API, or the local model, as chosen. The earlier report's plan was therefore always llama3.2.
- **Claude Code calls failed** when a local model name (qwen3) was left in settings, because that name was passed to Claude Code. Only Claude model names are passed now.
- **An em dash from the AI** reached the screen in a plan reason. AI reasons are now cleaned, and the plan prompt asks for plain sentences.
- **"Won't fit" text ran under its Move to Monday button.** It now wraps before the button (see `plan-claude-code-1920x1080` and `plan-ollama-llama3.2-1280x800`).
- **Screenshot runs after a long AI wait** closed the window in the same frame they asked for the picture, so no picture was saved. Fixed.
- A Board card could ask for a negative width and stop the app. Fixed before the Board was committed.
- The Board's "Done Monday" read the real clock, not the screenshot's, so the weekday moved with the time of day. Fixed.
- Dark pictures from the screenshot script showed Home instead of their screen; they were retaken one by one. A few pictures failed to save in the long batch and were retaken; each retake worked.
