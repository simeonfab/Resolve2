## Your three changes

1. **Voice.** No Whisper. The mic opens Windows voice typing (Win+H) on its own field. A new `mic_for(field)` in widgets.rs puts the field in focus first. The button shows Recording until the field loses focus or the mic is clicked again, which presses Win+H again and closes voice typing. Windows doesn't tell apps whether its voice typing panel is open, so this state follows the click and the focus, not the panel itself (**unverified** with a real microphone). It is used by Quick add, the Ask bar, the Ask sheet and the gallery.
2. **The "72%" figure.** It was not in my report. It came from Craft Anything's build check, which prints "It looks about N% like reference/picture-1.png" (this run: 68%). I can't show how that number is worked out, and it compares against the old Todoist-style reference picture, not the redesign. I won't quote it again.
3. **Em dashes.** This was the first Phase 1 commit (cddb6ac). I rewrote 149 on-screen strings in 31 files, plus 8 lines of the in-app tutorial, each one to fit its sentence. Pickers that showed a lone dash for "nothing" now say None or Empty. The divider block's icon is now `---`. A new self-check reads every string in `src/` and fails on an em dash. The only exceptions are 25 listed strings that never reach the screen: AI prompts, MCP text read by Claude or ChatGPT, terminal output and the word list used to shorten typed titles. Each exception has its reason in `src/selftest_p1.rs`. A second check covers TUTORIAL.md.

## 5. What I couldn't do, and why

- **Canvases.** No artifact tool here.
- **Red "First use of widget ID" marks on Home.** They were already there and appear in debug builds only. Home gives each task row an id from its task, and shows the same task twice when it is both due today and in the next 7 days or Captured. It's in dashboard.rs and widgets.rs `task_row`. I left it because Phase 2 rebuilds Home.
- **Search changes from the old palette.** The empty state is now the brief's ("Type to search…" with the type chips) instead of the old "Jump to" list (Home, Inbox, Today, Calendar, New page, New database, Settings, Toggle dark mode). "New page …" is also gone from the results, leaving the brief's 'Add "…" as a task'. Those actions still exist elsewhere (Ctrl+N, the page and database menus, Settings → Appearance). Say if you want any back in the palette.
- **The light/dark toggle in the sidebar's top row** is gone, because the brief's top row has no toggle. It is still in Settings → Appearance and works as before.
- **Em dashes in saved data.** Titles saved before today keep their em dash, for example an existing project plan page made by an earlier intake. AI replies can also contain em dashes. The sweep covers what the app writes. Rewriting saved data is a data change, so I'd only do that if you ask.
