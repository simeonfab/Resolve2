# Design canvases A to D

These are renders of the four approved design canvases, taken on 7 November 2026. Each PNG is one frame at its canvas size. Sample content in them (names, projects, tasks, dates) is placeholder. Where a render and the brief at `docs/briefs/2026-11-07-build-brief-packs-a-d.md` disagree, the brief wins. Each pack's `source/` folder holds every frame's HTML plus `canvas.json`, so builders can read exact values such as colours, spacing and timings. Motion frames show a single frame of a looping animation; read the source for the full timings.
