# Original Resolve: reference pictures and the agreed sections

5 November 2026. From Simeon.

These pictures come from the original Resolve design mockups (github.com/simeonfab/resolve-docs, mockups folder). They were designed for a phone screen, so treat them as a guide to the journey, the content, the tone and the look. They are not a layout spec for this desktop app. Fonts in the pictures fall back to a system serif where DM Serif Display did not load.

## The sections (decided)

Global sidebar, Linear-style:

1. Home: the dashboard across all projects (picture 12 and 13).
2. Projects
3. Calendar
4. AI Team: specialists and their conversations across projects.
5. Knowledge: shared documentation and reference material.
6. Settings

Top bar on every screen: Ask Resolve (the contextual global bar, picture 20), Search, Add task, New project (opens the intake).

Inside a project, six tabs:

1. Overview: objective, outcome, progress, "Decide this first", waiting on, today, worth a look, recent decisions. The original dashboard idea, for one project.
2. Roadmap: Now, Next and Later, viewable by phase or by theme (picture 15), plus milestones, dependencies and validation gates.
3. Work: Now, waiting on, captured and upcoming (picture 14), with list and board views. Replaces Tasks, Inbox, Today, Upcoming and Filters.
4. Validation: the Hypothesis Zero tree, experiments, evidence, assumptions, open questions and decisions in one place. A framework switcher sits here with Hypothesis Zero first. This merges the brief's Frameworks and Evidence and Records tabs, because evidence must stay next to the hypotheses and decisions it supports.
5. Knowledge: the project brief, documents, research, and the cut list of things deliberately not being done (picture 18).
6. Team: the leads, stand-up, agent chat and Handoff (pictures 16 and 17).

## The pictures, in journey order

Intake, the front door:

1. 01-intake-name-and-welcome: one question at a time, Enter to continue, greet by name once.
2. 02-intake-bring-it-in: one big free-text box for the messy version, plus the small "pull it in from another AI" prompt.
3. 03-intake-confirm-understanding: what Resolve understood, as cards the user edits, plus gap questions.
4. 04-intake-when-no-outcome: when there is no outcome to aim at, Resolve asks instead of guessing.
5. 05-intake-next-move: the recommended next move.
6. 06-intake-bridge: the bridge from intake into building the project.
